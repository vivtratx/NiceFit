# NiceFit – Clothing Shop Management Website

NiceFit is a team-based software engineering project developed as a clothing shop management web application.

The project integrates server-side application logic, EJS views, product data, images, user authentication, and a MySQL database.

## Technologies Used

- Node.js
- Express.js
- EJS
- JavaScript
- MySQL
- MySQL2
- Passport.js
- bcrypt
- Express Session
- HTML / CSS

## Project Overview

The purpose of NiceFit was to build a functional clothing shop system while practicing software engineering concepts such as team collaboration, application integration, database connectivity, debugging, and testing.

The repository contains:

- Server-side application logic
- EJS page templates
- Product and image resources
- MySQL database files
- Authentication configuration
- Application routing and supporting libraries

## Features

The project includes functionality related to:

- Product display
- Shopping cart
- Checkout workflow
- User login and registration
- Administrative pages
- Database-backed product information
- EJS-based dynamic page rendering
